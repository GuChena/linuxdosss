## 重要提醒

- 自动化工具可能违反社区规则或触发风控，请自行评估风险并合理使用。
- 自动点赞和自动回复默认关闭；启用自动回复时会弹出风险提醒。
- 程序不保存账号密码，登录在本机浏览器中完成。

## 功能特性

- **GUI 操作**：Tkinter 图形界面，支持实时日志、运行统计和升级进度追踪。
- **环境任务表格**：右侧展示序号、浏览器名、状态、完成时间和开始/停止/完成操作，同一时间只运行一个任务。
- **浏览模式**：支持深度爬楼和快速浏览两种模式。
- **运行模式**：支持无尽模式、帖子数量限制和时间限制。
- **未读优先**：默认只浏览带小蓝点的未读话题，避免已读帖直接跳到末楼。
- **回复数范围**：按板块列表页与浏览数平齐的“回复”列筛选话题，例如 `10-30`。
- **自动加载更多**：候选不足时可自动下滑话题列表加载更多，默认下滑 3 次。
- **真实点击进入**：从板块列表点击话题标题进入，返回后检查小蓝点是否消失。
- **系统托盘**：Windows/Linux 支持最小化到托盘并显示运行状态。
- **可选互动**：自动点赞、自动回复均可独立开关。

## 安装使用

### 方式一：Windows 一键启动

双击运行：

```bat
start.bat
```

脚本会自动创建 `.venv`、安装依赖并启动 GUI。

### 方式二：从源码运行

环境要求：

- Python 3.8+
- Chrome 浏览器

安装依赖：

```bash
pip install -r requirements.txt
```

启动：

```bash
python src/linux_do_gui.py
```

## 使用步骤

1. 启动 GUI。
2. 使用内置 Chromium 时，如需代理，在“代理”输入框填写地址；不需要则留空。指纹浏览器的代理在对应客户端中配置。
3. 选择运行模式：无尽模式、帖子数量或时间限制。
4. 选择浏览模式：深度爬楼或快速浏览。
5. 选择板块。
6. 设置回复数范围、列表下滑次数、等待时间等参数。
7. 点击“开始”，在打开的浏览器中完成登录。
8. 登录成功后程序自动开始浏览。

## 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 浏览器 | 内置Chromium | 可选「内置Chromium」、「比特浏览器」或「Simprint」 |
| 代理 | `127.0.0.1:7897` | 仅内置 Chromium 显示并使用，留空则不使用代理；指纹浏览器的代理由窗口或环境配置管理 |
| 自动点赞 | 关闭 | 开启后按点赞率随机点赞 |
| 点赞率 | 30% | 对主帖点赞的概率 |
| 自动回复 | 关闭 | 开启前会弹出风险提醒 |
| 回复率 | 5% | 对帖子回复的概率 |
| 等待时间 | 1-3 秒 | 话题之间、互动后的随机等待 |
| 回复数范围 | 0-120 | 只选择列表页“回复”列在范围内的话题；最大值留空表示不限 |
| 只浏览未读话题 | 开启 | 只选带小蓝点的未读话题 |
| 列表下滑 | 3 次 | 符合条件的话题不足时，向下加载更多列表内容 |

## 使用比特浏览器（指纹浏览器）

程序可接管比特浏览器打开的窗口，由比特浏览器管理指纹与代理，登录态随窗口持久化。

1. 打开比特浏览器客户端，在「设置 → 本地接口(API)」中确认 API 已开启及端口（默认 `54345`）。
2. 在本程序的「浏览器」一行选择「比特浏览器」，填写本地 API 端口。
3. 点击「获取窗口」，从右侧任务表格选择要使用的窗口。
4. 点击开始，程序会通过 API 打开该窗口并接管，结束时自动通过 API 关闭。

窗口列表和当前选择会保存到本地配置；点击「获取窗口」可随时刷新列表。
窗口列表支持滚动，每次只能选中一个窗口，显示格式为「序号 - 名字」；窗口 ID 仅作为内部连接标识保存。

> 比特浏览器模式下隐藏「代理」输入框，使用所选窗口的代理配置；运行期间请保持比特浏览器客户端开启。

## 使用 Simprint（指纹浏览器）

程序可通过 Simprint 本地 API 打开指定环境，并从浏览器进程中识别 remote debugging 端口后接管窗口。

1. 打开 Simprint 客户端，在「API & AI」中确认本地 API 已开启及端口（默认 `8080`）。
2. 在本程序的「浏览器」一行选择「Simprint」，填写端口和 Key。
3. 点击「获取环境」，程序会拉取全部 Simprint 环境，并只保留分组名等价于 `Linux.do` 的环境；`linuxdo`、`Linuxdo`、`linux.do` 都会被识别为 `Linux.do`。
4. 在右侧任务表格选择要使用的环境，每次只能选中一个；表格支持鼠标滚轮滚动，并会保存当前选择。
5. 点击开始，程序会通过 API 打开该环境；结束时自动通过 API 停止环境。

> Simprint 模式下隐藏「代理」输入框，使用所选环境的代理配置；运行期间请保持 Simprint 客户端开启。

## 环境任务表格

比特浏览器和 Simprint 的表格包含「序号、浏览器名、状态、完成时间、操作」五列。浏览器名沿用原来的显示名称，不附加 “[ready]”。名称列按最长名称适配，表格不显示滚动条，可用鼠标滚轮浏览更多行。

- **开始**：按左侧当前参数启动该行环境。启动、等待登录、运行和停止收尾期间，其余环境和全局入口都不能开始新任务。
- **停止**：请求中断当前任务，先显示「正在停止」。已登录的任务会先刷新最新升级进度、更新显示和日志，再关闭浏览器；后台退出后显示「已停止」，不产生新的完成时间。收尾期间仍不能启动其他任务。
- **完成**：手动标记本轮任务完成。运行中的环境先停止，按相同流程检查最新升级进度并关闭浏览器，再记为「已完成」；尚未运行或已经停止的环境可直接标记完成。
- **自动完成**：帖子数量或时间达到目标后自动记录完成。数量目标未达到时会继续下一轮板块浏览；启动失败、登录失败或运行异常显示「异常」。
- **完成记录**：按浏览器类型和环境 ID 保存，同名环境互不影响。完成时间显示最近一次完成的时间，记录在重启后保留；再次开始时更新任务状态，不按日期自动清零。
- **意外退出恢复**：上次仍处于运行或停止收尾的任务，重启后恢复为「已停止」，不会自动启动。

左侧日志和本次统计显示当前或最近一次任务。开始/停止按钮仍位于浏览器设置第二行，与表格行内按钮使用同一套运行限制。

## 浏览逻辑

当前 GUI 版的话题选择流程：

```text
进入勾选板块
→ 不点击“回复”排序
→ 扫描当前已加载的话题列表
→ 读取每行“回复”列数字
→ 按回复数范围筛选
→ 默认只保留未读小蓝点话题
→ 候选不足时自动下滑加载更多
→ 去重合并候选
→ 随机抽取 3-8 个话题进入
```

## 支持的板块

默认启用：开发调优、国产替代、资源荟萃、网盘资源、文档共建、非我莫属、读书成诗、前沿快讯、网络记忆、福利羊毛、搞七捻三、虫洞广场。

默认禁用：积分乐园、扬帆起航、社区孵化、运营反馈。
